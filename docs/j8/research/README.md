# J8 research notes (supporting material)

These files are working research for the Samsung Galaxy J8 (`SM-J810G`,
`j8y18lte`, Snapdragon 450 / msm8953) port. They are inputs to
`docs/j8/FEASIBILITY.md`, `docs/j8/HARDWARE.md` and `docs/j8/STATUS.md`;
the top-level documents in `docs/j8/` are the authoritative summaries.

Each note records its sources with URLs and access dates. Anything not
verified on this device is labelled as documented, inferred or untested.
